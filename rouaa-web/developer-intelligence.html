Code Example

Five lines to a verified fact.
A few more to a live event stream.

Typed SDKs, evidence attached to every response, and streaming that preserves provenance end-to-end. This is what your integration looks like.

TypeScript — Retrieve a verified fact with its evidence chain
import { RouaaClient } from "@rouaa/sdk";

const rouaa = new RouaaClient({
  apiKey: process.env.ROUAA_API_KEY,
  environment: "production",
});

// Retrieve a verified fact — evidence chain attached by default
const fact = await rouaa.facts.retrieve("FCT-7E3A91", {
  includeEvidence: true,
  includeSources: true,
});

console.log(fact.statement);
// → "ECB raises deposit facility rate by 25 bps to 4.00%."

console.log(fact.confidence, fact.verificationTier);
// → 0.97  "T1 — official primary source"

// Every fact arrives with its full evidence chain
for (const node of fact.evidenceChain) {
  console.log(node.source.uri,    // ecb.europa.eu
              node.paragraph,     // 3
              node.excerpt);      // "The Governing Council decided to raise..."
}
Python — Stream material events with provenance preserved
import os
from rouaa import RouaaClient
from rouaa.streaming import EventFilter

client = RouaaClient(api_key=os.environ["ROUAA_API_KEY"])

# Stream material events as the engine verifies them
stream = client.events.stream(
    filter=EventFilter(
        entity_ids=["LEI:5493001KJTIIGC8Y1R12"],   # ECB
        event_types=["monetary_policy", "rate_decision"],
        min_confidence=0.85,
        tiers=["T1", "T2"],
    )
)

for event in stream:
    print(event.type, event.timestamp.isoformat())
    print(" ", event.payload.summary)

    # Provenance travels with every streamed event
    for source in event.evidence:
        print("    -", source.uri,
              "¶", source.paragraph,
              source.excerpt[:80])
