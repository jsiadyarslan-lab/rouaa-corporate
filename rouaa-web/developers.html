Intelligence APIs

Six API families. One evidence chain.

Every API returns the same evidence-linked intelligence — facts carry source documents, page numbers, paragraphs, and confidence scores.

Sources API

Query the 411+ official source registry.

List sources by type, country, jurisdiction, trust tier, status. Get source health, ingestion patterns, monitoring configuration. Filter by central bank, regulator, exchange, statistical agency, government body, or international organization.

Documents API

Access processed official documents.

Retrieve ingested documents with classification, language detection, and processing status. Full-text search across documents. Link to original source URLs and ingestion metadata.

Facts API

Query verified financial facts with provenance.

Every fact returns: value, source document, page number, paragraph, extraction confidence, corroboration count, publication timestamp. Filter by metric, source, jurisdiction, or confidence threshold.

Events API

Detect and subscribe to financial events.

Get notified when financial events are detected — rate decisions, earnings releases, regulatory actions, statistical releases. Every event carries its evidence chain and impact assessment.

Evidence API

Retrieve full provenance chains for any claim.

Given any fact or analysis output, return the complete evidence chain — source document, page, paragraph, extraction confidence, governance validation, corroboration sources. Reconstructable on demand.

Intelligence API

Generated intelligence products on demand.

Request research briefs, market analysis, scenario intelligence, or news drafts — all generated from verified evidence with full provenance. Returns review-ready output for editorial or committee workflows.

Real-time Streaming

Stream events as they happen.

WebSocket endpoints push verified financial events the moment they're detected — typically within seconds of official source publication.

Event Stream

Real-time feed of detected financial events. Subscribe by type, source, jurisdiction, or entity. Every event includes evidence chain.

Fact Stream

Verified facts as they're extracted and governance-validated. Subscribe by metric, source, or confidence threshold.

Source Health Stream

Monitor source availability, ingestion failures, and reliability scores in real time. Operational visibility into the registry.

Code Examples

From API key to first fact in 60 seconds.

REST + streaming + SDKs in TypeScript, Python, and Go. Every response carries full provenance — no separate verification call needed.

TypeScript · Fetch a verified fact with evidence chain
GET /api/v1/facts/:id?include=evidence
// Fetch a verified fact with full evidence chain
const response = await fetch(
  'https://api.rouaa.com/v1/facts/fed-funds-rate-jul-2026?include=evidence',
  { headers: { 'Authorization': 'Bearer ' + apiKey } }
);

const fact = await response.json();

// Every fact carries its full provenance
console.log(fact.value);              // "5.25-5.50%"
console.log(fact.metric);             // "federal_funds_rate_range"
console.log(fact.confidence);         // 0.97
console.log(fact.source.name);        // "Federal Reserve"
console.log(fact.evidence.page);      // 1
console.log(fact.evidence.paragraph); // 3
console.log(fact.evidence.documentUrl); // https://...fomcstatement.pdf
Python · Stream events as they happen
WebSocket /v1/stream/events
# Subscribe to verified financial events in real time
from rouaa import RouaaClient

client = RouaaClient(api_key="rk_live_...")

# Stream events as they're detected and validated
for event in client.events.stream(
    types=["rate_decision", "earnings_release"],
    jurisdictions=["US", "EU", "SA"],
    min_confidence=0.85
):
    print(f"{event.detected_at} · {event.type} · {event.title}")
    print(f"  Source: {event.source.name} ({event.source.tier})")
    print(f"  Evidence: {len(event.evidence_chain)} steps")
