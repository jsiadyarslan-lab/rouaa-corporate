Engineering Architecture

How the system is built.

The patterns and technologies that make the 7-layer architecture production-grade.

⚡
Event-Driven Core
Source detections, fact extractions, and event detections flow through an event-driven pipeline. Each stage emits events that trigger downstream processing — no polling, no batch delays.
📋
Queue-Based Processing
BullMQ + Redis queues manage ingestion, processing, and intelligence generation workers. Horizontal scaling per layer.
📊
Streaming + Batch
Real-time streaming for event detection and alerts. Batch processing for report generation and deep analysis. Both share the same evidence layer.
🔗
Graph Database
PostgreSQL + pgvector for relational and vector storage. Knowledge Graph built on entity-relationship model — queryable across entities, events, facts, and evidence chains.
🔌
API Layer
NestJS REST API + WebSocket streaming + SDK layer. OpenAPI 3.1 spec. Rate-limited, authenticated, audited. Every API response carries evidence provenance.
🔍
Search Layer
Full-text search across documents, facts, events, and intelligence products. pg_trgm for fuzzy matching. Vector similarity for semantic search across the knowledge graph.
