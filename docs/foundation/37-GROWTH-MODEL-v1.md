# 0. لماذا هذه الوثيقة؟

العديد من الشركات التقنية تفشل ليس بسبب ضعف المنتج.

بل بسبب خطأ النمو.

تبني:

- ميزات كثيرة
- مستخدمين كثيرين
- حركة تسويقية واسعة

لكن لا تبني:

- فئة سوقية
- حسابات مؤسسية
- توسع داخل المؤسسات
- أصل معرفي يتراكم

---

## قاعدة النمو في رؤى

رؤى لا تنمو عبر:

```

```

```

   ↓

   ↓

   ↓

   ↓

```
