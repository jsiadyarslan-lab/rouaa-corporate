# 0. Purpose

تجيب عن سؤال:

> كيف تتحول القيمة المؤسسية التي تقدمها رؤى إلى نموذج إيرادات قابل للتوسع، قابل للتقييم الاستثماري، ومناسب للمؤسسات المالية الكبرى؟

الفرضية:

> رؤى لا تبيع بيانات، ولا أدوات AI، ولا مقاعد مستخدمين.
> رؤى ترخّص طبقة بنية تحتية للقرار المؤسسي.

---

# 1. Pricing Philosophy

## الخطأ التقليدي

معظم SaaS:

```
Users × Monthly Fee
```

لكن رؤى:

```
Decision Criticality
+
Institutional Scope
+
Integration Depth
+
Knowledge Asset Access
+
Usage Scale
```

لأن قيمة القرار تختلف جذرياً:

* تقرير بحثي داخلي
* قرار لجنة استثمار
* قرار تداول
* تقرير امتثال تنظيمي

ليست نفس القيمة.
