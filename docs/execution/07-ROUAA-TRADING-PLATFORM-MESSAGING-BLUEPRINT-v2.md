## Capability 5: Automated Executors

### Headline

```
Automated Executors
```

### Message

```
Automate predefined workflows
with control and auditability.
```

### What it means (plain language)

```
This is NOT an autonomous trading bot.

This is governed automation:
  • You define the rules

You stay in control.
ROUAA handles the execution speed.
```

- Pause / modify / stop controls
- Performance monitoring

- "Autonomous trading bot"
- "Automated execution layer"
- "Trading workflow automation engine"

# 10. Vocabulary Lock for Trading Platform Page

| Use | Don't use | Why |
|---|---|---|
| AI Trading Council | Multi-agent reasoning system | "Council" is understandable; "system" is technical |
| Smart Chart Intelligence | Chart annotation engine | "Intelligence" is value; "engine" is internal |
| Market Scanner | Signal intelligence pipeline | "Scanner" is familiar; "pipeline" is internal |
| Predictive Markets | Prediction engine | "Predictive Markets" implies scenarios; "engine" implies one answer |
| Automated Executors | Automated execution layer | "Executors" are tools; "layer" is architecture |
| Governed automation | Autonomous trading | "Governed" = user in control; "Autonomous" = AI in control |
| Context | Decision context | "Context" is simpler |
| Evidence | Provenance | "Evidence" is institutional; "Provenance" is academic |
| Request Demo | Request Institutional Briefing | "Demo" is actionable; "Briefing" is abstract |
