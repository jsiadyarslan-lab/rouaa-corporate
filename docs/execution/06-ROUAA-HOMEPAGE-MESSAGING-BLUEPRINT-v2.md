# 6. Vocabulary Lock for Homepage

| Use | Don't use | Why |
|---|---|---|
| Platforms | Infrastructure | We sell platforms, not infrastructure |
| Built on verified intelligence | Financial Intelligence Infrastructure | Infrastructure is the differentiator, not the product |
| Trading Platform | Trading Technologies | "Technologies" sounds like a vendor, not a product |
| AI-powered | AI-powered | OK to use — it's a capability claim, not hype |
| Verified intelligence | Intelligence engine | "Engine" is internal, "intelligence" is what the user gets |
| Better decisions | Better decisions | OK — outcome-focused |
| Evidence | Provenance | "Provenance" is academic; "Evidence" is institutional |
| Context | Decision context | "Context" is simpler and sufficient |
