SDK وأمثلة الكود

ادمج رؤى في تطبيقاتك

SDK رسمي لـ Python و JavaScript و Go. مثال واحد يكفي لبدء الاستهلاك — مع دليل لكل استجابة.

Python JavaScript cURL
# تثبيت pip install rouaa-sdk # تهيئة from rouaa import Rouaa client = Rouaa(api_key="rk_live_...") # الحصول على أحدث الإشارات signals = client.signals.list( pair="EUR/USD", min_confidence=0.7 ) for signal in signals: print(signal.pair, signal.direction, signal.confidence) # كل إشارة لها سلسلة أدلة كاملة for evidence in signal.evidence: print(f" ← {evidence.source} · {evidence.document}")

مصادقة مؤسسية

كل طلب يتطلب مفتاح API. الحدود تختلف حسب الخطة. المؤسسي: حدود أعلى + دعم مخصص + SDK access كامل.

ميزات التكامل

طبقات تكامل متعددة

REST للطلبات التقليدية · Streaming للبيانات الحية · Webhooks للأحداث · SDK لكل لغة.

01
واجهة REST
وصول كامل لكل طبقات رؤى — المصادر، الحقائق، الأدلة، المجلس، الإشارات، التنفيذ، المحفظة.
02
بث مباشر
بث مباشر للإشارات والأحداث — WebSocket · SSE. زمن استجابة أقل من 100مللي.
03
Webhooks
تنبيهات فورية عند الأحداث الحرجة — الفيدرالي، التضخم، الوظائف. تكامل مع Slack، البريد، SMS.
04
SDK بايثون
pip install rouaa-sdk · مكتبة كاملة · دعم async · type hints.
05
SDK جافا سكريبت
npm install @rouaa/sdk · Node.js + المتصفح · TypeScript native.
06
SDK Go
go get github.com/rouaa/rouaa-go · للأعباء العالية · concurrent native.
