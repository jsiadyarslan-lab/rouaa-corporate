SDK & Code Samples

ادمج رؤى في تطبيقاتك

SDK رسمي لـ Python و JavaScript و Go. مثال واحد يكفي لبدء الاستهلاك.

Python JavaScript cURL
# Install pip install rouaa-sdk # Initialize from rouaa import Rouaa client = Rouaa(api_key="rk_live_...") # Get latest signals signals = client.signals.list( pair="EUR/USD", min_confidence=0.7 ) for signal in signals: print(signal.pair, signal.direction, signal.confidence) # Each signal has full evidence chain for evidence in signal.evidence: print(f" ← {evidence.source} · {evidence.document}")
Integration Features

طبقات تكامل متعددة

REST للطلبات التقليدية · Streaming للبيانات الحية · Webhooks للأحداث · SDK لكل لغة.

01
REST API
وصول كامل لكل طبقات رؤى — sources, facts, evidence, council, signals, execute, portfolio.
02
Streaming
بث مباشر للإشارات والأحداث — WebSocket · SSE. زمن استجابة <100ms.
03
Webhooks
تنبيهات فورية عند الأحداث الحرجة — FOMC, CPI, NFP. تكامل مع Slack, Email, SMS.
04
Python SDK
pip install rouaa-sdk · مكتبة كاملة · async support · type hints.
05
JavaScript SDK
npm install @rouaa/sdk · Node.js + Browser · TypeScript native.
06
Go SDK
go get github.com/rouaa/rouaa-go · للأعباء العالية · concurrent native.
