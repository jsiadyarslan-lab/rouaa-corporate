API Capabilities

أربع واجهات. ذكاء واحد.

Events API GET

أحداث مالية رسمية — قرار فائدة، CPI، GDP، أرباح، جيوسياسي

GET /v1/events
?type=monetary_policy
&country=US
&since=2026-07-01

→ 38 events
→ each with evidence
Facts API GET

حقائق موثقة — كل رقم مرتبط بمصدر وصفحة وفقرة

GET /v1/facts
?topic=inflation
&country=US

→ {
value: "3.2%",
source: "BLS",
evidence: "p.4 ¶2"
}
Intelligence API GET

تحليل + تأثير + سياق سوقي + تقييم مخاطر

GET /v1/intelligence
/event/fomc-2026-07

→ impact analysis
→ market context
→ risk assessment
→ quality scores
Knowledge Graph API GET

شبكة العلاقات المالية — كيانات، أحداث، تأثيرات مترابطة

GET /v1/graph
?entity=federal_reserve
&depth=2

→ Company → Country
→ Sector → Event
→ Event → Impact
Evidence-Native API

كل استجابة تحمل دليلها

ليست مجرد JSON. كل استجابة من رؤى تحتوي على سلسلة الأدلة — المصدر، الوثيقة، الصفحة، الفقرة. بياناتك موثوقة من الأصل.

GET /v1/intelligence/event/fomc-2026-07 200 OK
{
"event": "Federal Reserve Rate Decision",
"impact": "USD volatility expected",
"intelligence": {
"interpretation": "Inflation cooling confirmed",
"quality": {
"evidence_quality": "A+ (98%)",
"reasoning_strength": "A (87%)",
"scenario_probability": "B+ (64%)"
}
},
"evidence": {
// ← كل استجابة تحمل دليلها
"source": "Federal Reserve",
"document": "FOMC Statement July 2026",
"page": 2,
"paragraph": 4,
"url": "federalreserve.gov/...",
"verified": true
}
}

Polygon يعطيك أرقاماً. Alpha Vantage يعطيك أسعاراً. رؤى تعطيك معنى موثّقاً بالدليل.
